# Three.js projects

Small 3D experiments for the web, built with [Three.js](https://threejs.org) and TypeScript. Each folder is its own project with its own README.

| Project | What it is |
|---|---|
| [Pocket island](pocket-island) | My story so far as a tiny low-poly floating island. Drag to spin it, tap a place to learn more. The lighting follows the real time in Toronto. |
| [Skills carousel](skills-carousel) | The tools I work with, as logos on a spinning 3D ring. Work in progress. |

## Run a project

```bash
cd pocket-island
npm install
npm run dev
```
